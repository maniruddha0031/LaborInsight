# Vendored libraries

Both libraries are bundled so the portal works offline after cloning. Neither is modified.

| File | Library | Version | License | Purpose |
|---|---|---|---|---|
| `fflate.min.js` | [fflate](https://github.com/101arrowz/fflate) (UMD build) | 0.8.2 | MIT | Streaming ZIP inflate in the Web Worker and in Node |
| `chart.umd.min.js` | [Chart.js](https://www.chartjs.org/) | 4.4.1 | MIT | Bar and line charts |

Fonts (IBM Plex Sans / Condensed) load from Google Fonts when online. Offline, the page falls back to system fonts.
